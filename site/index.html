Cockpit is a desktop front-end for Claude Code. Every session gets its own worktree. Everything that needs you lands in one queue, drawn as cards, plans and change maps you can act on with one key.

Your Claude. Your machine. No server.

Cockpit drives the claude you already use, through Anthropic's official Agent SDK, signed in as you. Every message goes to a local, append-only SQLite log, and the UI is a replay of it.

React UI ──IPC──▶ Rust core ──stdio──▶ sidecar (Agent SDK) ──▶ your `claude` │ ▲ └──── local SQLite event log ◀────────┘
No tokensNever reads or stores your credentials.
No serverNothing leaves your machine except your own Claude Code traffic.
No lock-inSessions are normal Claude Code sessions. Resume them in a terminal any time.

Windows

Windows 10/11 · x64
  1. macOS: drag Cockpit to Applications, then run xattr -dr com.apple.quarantine /Applications/Cockpit.app once (it isn't notarized yet).
  2. Linux: chmod +x Cockpit_*.AppImage and run it, or install the .deb / .rpm.
  3. Windows: run the setup .exe. If SmartScreen warns, choose More info → Run anyway.

All builds and checksums: GitHub Releases. macOS is the daily driver; Linux and Windows are new, so please report anything odd.

Questions

Does it cost anything?

No. Cockpit is free and MIT licensed. Sessions use your existing Claude plan (Pro, Max, Team or API), exactly as Claude Code in a terminal does. An optional layer that draws richer views needs your own Anthropic API key, and it meters its cost in the app.

Is this made by Anthropic?

No. It's an independent open-source project built on Anthropic's public Agent SDK. "Claude" and "Claude Code" are Anthropic's trademarks.

Will my skills, commands, hooks and CLAUDE.md still work?

Yes. Cockpit runs your real Claude Code with your real configuration. Workspaces keep memory and history apart per client while sharing your skills, commands and settings.

What if a visual is wrong?

The raw transcript is always one key away, and approvals always show exactly what will run. In god mode you can mark the mistake, and Cockpit opens a session to fix itself.

Can I build it myself?

Yes: git clone https://github.com/kostkobv/cockpit && cd cockpit && ./scripts/dev.sh. You need Rust and Bun.
